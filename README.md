# Habit Tracker

A simple and modern habit tracking application designed to help you build consistency, monitor your daily progress, and review your habits over time.

## 🚀 Live Application

**[Open Habit Tracker](https://abhinav-k-singh.github.io/Habit_Tracker/)**

Use the live application to:

* ✅ Track daily habits
* 📅 Maintain your daily history
* 📊 Review your progress and statistics
* 🎯 Set and monitor goals
* ☁️ Sync your data securely with your account
* 📱 Use the tracker comfortably on desktop and mobile

## 🔐 Data & Accounts

The application supports user accounts and cloud-based data storage. Each user has their own habit-tracking data, allowing progress and history to remain associated with their account.

## 📱 Designed for Everyday Use

The interface is responsive and optimized for both desktop and mobile devices, making it easy to update habits wherever you are.

## 🌐 Use the App

You don't need to download or install anything.

Simply open:

**https://abhinav-k-singh.github.io/Habit_Tracker/**

and start tracking your habits.
